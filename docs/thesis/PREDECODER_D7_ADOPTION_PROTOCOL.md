# d7 논리 클래스별 채택 모델 평가 규약

2026-11-17 · 학습 후보 생성기 대조 실험의 후속 평가. 개발 맵에서 채택 모델과 기준값을 고정한 뒤 새 평가 맵을 생성한다.

## 비교 조건

d7, 7라운드, Bell-pair Z readout, `p=0.0015`의 강한 ZZ G₁(`zz_factor=0.25`)에서 같은 맵의 G₀(`zz_factor=0.05`) DEM을 사용하는 일반 PyMatching(D₀)을 기준으로 둔다. 학습 후보는 기존 checkpoint 0–7의 원본 유지 1개와 CNN 순위에 따른 고유 편집 최대 32개다.

원본 클래스가 `r`일 때 모델은 실제 정답과 원본의 XOR 값 0, 1, 2, 3의 확률을 다항 로지스틱 회귀로 추정한다. 확률의 학습에는 모든 shot을 사용한다. `c ≠ 0`인 대안의 확률과 원본 확률의 차이는 해당 논리 전환의 추정 순이득이다. 허용된 대안 중 확률이 가장 높은 클래스의 추정 순이득이 기준값을 초과할 때만 전환한다. 동률과 대안 부재 시 원본을 유지한다. 대안끼리 동률이면 XOR 값이 작은 대안을 고른다. 후보 제약이 있는 정책은 해당 클래스를 내는 가장 앞선 편집 후보를 사용한다.

| 정책 | 입력 | 허용된 대안 |
| --- | --- | --- |
| 학습 후보 채택 | 원본 논리 클래스, 라운드별 detector event 수, 원본 MWPM 최솟값, 원본 syndrome의 클래스별 제약 matching 비용 차이와 도달 여부. 여기에 각 후보 클래스의 비중, 첫 등장 순위, 편집 후 MWPM 비용 변화의 최솟값과 평균을 추가 | 학습 후보가 출력한 클래스 |
| 비용 모델, 후보 제약 | 같은 원본 특징으로 학습한 비용 모델의 확률 | 학습 후보가 출력한 클래스 |
| 비용 모델, 제약 없음 | 같은 비용 모델의 확률 | 원본 syndrome에서 제약 matching으로 도달 가능한 클래스 |

원본의 제약 비용은 기존 검증된 경계 parity 열거로 계산하고, 매 shot에서 일반 MWPM의 비용과 일치하는지 확인한다. 편집 후 비용은 수정된 syndrome에서 일반 MWPM이 반환한 비용이다. 두 모델은 개발 데이터에서 특징을 표준화하고 절편을 제외한 L2 계수 0.01을 사용한다. 정답은 모델 학습과 성능 집계에 사용한다. 원본 특징과 후보 특징의 계산에는 정답 및 정답 집계를 사용하지 않는다.

## 개발 및 독립 평가

앞선 후보 생성 비교에 사용한 맵 788200–788223을 개발에 사용한다. 저장된 후보 mask를 다시 디코딩하고 기존 논리 예측과 대조한다. 한 번에 맵 하나를 제외해 모델을 적합하고, 제외한 맵에 각 기준값을 적용한다. 기준값은 `0, 0.01, 0.025, 0.05, 0.10, 0.20, 0.35, 0.50`이다. 정책별로 맵 평균 순이득이 최대인 값을 고르고 동률이면 가장 큰 값을 사용한다. 최종 모델은 개발 맵 전체로 다시 적합한다.

독립 평가 맵은 788300–788323이며 sampler seed는 1794300–1794347로 G₀ 다음 G₁ 순이다. 맵마다 G₀ 32 shot으로 D₀ 생성 조건을 공유하고, G₁ 512 shot을 평가한다. 이전 데이터와 seed 중복을 검사한다. 맵·checkpoint·코드·패키지 버전과 학습된 계수 및 기준값을 데이터 생성 전에 기록한다.

주 비교는 학습 후보 채택 정책 대 원본 PyMatching과 학습 후보 채택 정책 대 후보 제약을 공유하는 비용 모델이다. 두 observable을 모두 맞힌 경우를 정답으로 센다. 같은 shot에서 고친 오답 수와 해친 정답 수의 차이를 정확도 차이로 계산한다. 후보 제약 정책은 각 맵에서 checkpoint 8개를 동일 가중한다. 맵별 짝차이 24개의 평균과 양측 97.5% Student t 구간을 보고해 두 주 비교의 전체 오차율을 관리한다. 하한이 0보다 크면 해당 비교에서 개선을 확인한다. 두 비용 정책의 원본 대비 95% 구간은 기술 통계다. 추론은 고정한 checkpoint 패널에 조건부다.
