# d7 편향 잡음 채택 모델 재학습 규약

기존 편향 독립 평가에서는 고친 수와 해친 수가 205 대 203으로 상쇄됐다.
이번 실험은 기존 후보 CNN을 고정하고, eta=20 자료에서 채택 모델을 새로 학습한다.
별도 학습·개발·평가 맵을 사용하며, 이전 독립 평가 맵은 학습에 포함하지 않는다.

## 고정 조건

회로는 d=7, 7 rounds의 rotated surface code와 Bell-pair readout이다.
Stage C의 p=0.0015, ZZ 계수 0.05, swap 계수 0.02를 사용한다.
데이터 큐비트의 단일 큐비트 gate·idle 채널을
eta = p_Z/(p_X+p_Y) = 20, p_X = p_Y로 구성하고 각 위치의 총 오류 확률을 유지한다.
기준선은 각 맵의 실제 편향 회로에서 만든 DEM의 일반 MWPM이다.

후보 생성기는 A/B 재학습 seed 2의 CNN과 기존 motif 집합이다.
원본 유지 후보 1개와 비영 후보 32개를 사용한다.
후보 CNN의 가중치와 motif는 이번 학습에서 고정한다.
context는 파일럿의 균등 단일 큐비트 채널 기준 메타데이터를 사용하고,
detector event fraction은 기존 고정값 0.042736961728050596,
라벨 집계 채널은 0으로 둔다.

| 자료 | Local map seed | Sampler seed | 표본 수 |
| --- | --- | --- | ---: |
| 학습 | 788700–788731 | 1887000–1887031 | 32 × 2,048 = 65,536 |
| 기준 선택 | 788740–788747 | 1887400–1887407 | 8 × 2,048 = 16,384 |

## 채택 모델과 기준 선택

기존 4-class logistic regression 구현을 재사용하고 L2=0.01로 고정한다.
학습 target은 원본 MWPM 논리 클래스와 정답 클래스의 XOR이다.
클래스는 0=I, 1=X, 2=Z, 3=Y로 정의한다.

입력은 원본 matching 비용, 원본 논리 클래스, 라운드별 detector event 수,
네 논리 클래스의 상대 matching 비용과 도달 가능 여부,
후보가 제공한 각 논리 전환의 수·첫 순위·수정 후 matching 비용 요약이다.
클래스별 matching 비용은 기존의 일반 MWPM boundary-parity 계산을 사용하고,
원본 최적 비용과 일치하는지 검증한다.
특징 계산에는 실제 정답을 전달하지 않는다.
정답은 학습 target과 평가 지표를 구할 때 사용한다.

모델은 학습 맵에서만 적합한다.
기준 선택 맵에서는 후보가 제공한 최선의 대안 전환 확률에서
원본 유지 확률을 뺀 차이가 기준값을 초과할 때 전환한다.
원본 유지에는 항상 원본 후보를 사용하며, 후보가 제공하지 않은 전환은 선택하지 않는다.
같은 논리 클래스를 내는 후보가 여럿이면 기존 순위에서 첫 후보를 사용한다.

기준값 후보는 0, 0.01, 0.025, 0.05, 0.10, 0.20, 0.35, 0.50, 1.0이다.
개발 맵의 평균 순이득을 최대화하는 값을 고른다.
동률이면 더 높은 값을 택한다. 기준 1.0은 모든 입력에서 원본 유지에 해당한다.
모델과 기준값을 policy.json에 고정하고, 기준 선택 뒤 모델을 다시 적합하지 않는다.

학습·개발 특징은 기존의 배치 후보 생성 함수를 사용한다.
독립 평가에서는 기존 margin 정책의 후보 경로를 함께 실행하고,
같은 후보와 matching 결과로 새 채택 정책을 평가한다.
편향 자료 32 shots에서 두 후보 생성 경로의 mask·특징·논리 예측 일치를 확인한다.

## 독립 평가와 검증

주 비교는 새 채택 정책 대 편향 MWPM이다.
같은 shot의 고친 수와 해친 수를 구하고, 맵별 정확도 차이를 동일 가중치로 평균한다.
양측 95% Student t 구간의 하한이 0을 초과하면 추가 개선을 지지한다.
기존 margin 정책 대비 새 정책의 차이는 보조 비교로 95% 맵 구간을 보고한다.
원본과 기존 margin도 같은 새 shot에서 비교한다.

두 logical observable 중 하나라도 틀리면 joint logical error로 센다.
독립 평가에서는 모델, 기준값, 표본 수를 바꾸지 않는다.
저장된 후보 클래스와 실제 선택한 후보의 복호화 결과를 대조한다.
소스·checkpoint·자료·특징·예측 해시를 보관하고 저장 배열에서 지표와 구간을 재계산한다.

수치 조건은 기존 편향 실험의 Stim 텍스트 반올림과 DEM 근사를 따른다.
이번 결과는 고정 후보 CNN 하나와 학습된 채택 모델 하나에 조건부다.
CPU 작업 두 개로 실행하므로 평가 경과 시간은 별도 배치 지연 측정값으로 사용하지 않는다.
