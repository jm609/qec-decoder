# d7 활성 selector의 DEM·디코더 교차 평가

2026-11-17 · Anaconda `fp` · 논문 완성 계획 3단계

강한 ZZ에서 shot별 margin의 순이득은 전체 경로 재계산 기준으로 개발 맵 **+0.009~+0.027 pp**, 보정 맵 **−0.024~+0.006 pp**였다. Paired detector head의 강한 ZZ 순이득은 개발 맵 네 디코더 조건에서 모두 음수였다. D₁이나 correlated PyMatching을 쓰면 원본 정확도와 수정 선택이 바뀌었지만, 기존 margin의 순이득은 두 맵 묶음에서 같은 방향으로 유지되지 않았다. [집계·맵별 결과](../../../artifacts/eval/d7_active_prior/20261117/summary.json)

## 실험 조건

2단계의 개발 맵 787000–787003과 별도 보정 맵 787100–787101을 재사용했다. 각 맵·강도에 1,024 shot, d7 checkpoint seed 0–7을 적용했다. 따라서 강도당 개발 4,096 shot에서 32,768 모델–shot 쌍, 보정 2,048 shot에서 16,384 모델–shot 쌍을 비교했다. 두 observable이 모두 맞은 shot을 정답으로 셌다.

D₀는 G₀ 회로의 DEM, D₁은 G₁ 회로의 DEM이다. 같은 shot을 네 디코더 조건으로 평가했다. 기존 shot별 margin과 paired detector head의 cutoff 0을 유지했다. 개발 맵에는 각 맵을 학습에서 제외한 2단계 fold head를, 보정 맵에는 개발 G₁ 네 맵으로 적합한 2단계 head를 사용했다. 같은 맵에서 네 디코더 조건에 동일한 head를 적용했다. [동결 규약](../../../artifacts/eval/d7_active_prior/20261117/protocol.json)

- **행동 고정.** D₀ 일반 MWPM에서 선택한 edit mask를 그대로 적용하고, 해당 셀 디코더로 수정 syndrome을 디코딩했다. 순이득은 같은 셀의 원본 예측을 기준으로 계산했다.
- **전체 경로.** 해당 셀에서 원본·후보 syndrome의 논리 예측, 전이 특징, utility, margin·paired 선택을 다시 계산했다. 후보 mask와 신경망의 syndrome·기하 특징은 디코더 입력에 의존하지 않아 공통으로 계산했다. 입력 context는 2단계와 같이 해당 맵의 G₀ 설정을 유지했다.

공통 후보 묶음을 재사용하기 전에 각 강도의 64 shot에서 3개 대안 디코더로 후보 생성부터 직접 재실행했다. 모든 대안에서 후보 특징, utility, 선택 mask, 논리 예측이 일치했다. [직접 재실행 검증](../../../artifacts/eval/d7_active_prior/20261117/rescore_replay.json)

### 같은 수정과 다시 고른 수정

강한 ZZ에서 일반 MWPM의 DEM을 D₀에서 D₁로 바꿨을 때, 고정한 margin 수정의 순이득은 개발에서 +0.012에서 +0.009 pp, 보정에서 −0.018에서 −0.012 pp로 바뀌었다. 원본 정확도는 각각 −0.024 pp, 0.000 pp 변했다. 이 설정에서 matched DEM이 활성 정책의 이득을 일관되게 늘린다는 근거는 없었다.

보정 G₁/D₁ correlated에서 고정 margin mask는 61건을 수정해 순정답 5건을 잃었다. 전체 경로에서는 30쌍의 mask가 달라졌고, 67건을 수정해 34건 개선, 33건 악화를 기록했다. 부호는 바뀌었지만 최종 차이는 순정답 1건(+0.006 pp)이다. 개발 G₁에서 margin의 전체 경로 순이득은 네 조건 모두 작게 양수였고, 맵 단위로는 각 조건에서 음수인 맵이 있었다. 이 결과로 새 맵에서의 개선을 확정하기 어렵다.

### 원본 디코더 정확도

약한 ZZ에서 D₀ 일반을 D₀ correlated로 바꾸자 raw 정확도가 개발 **+0.342 pp**, 보정 **+0.195 pp** 올랐다. 이 변화 폭은 같은 correlated 원본에 margin을 더한 전체 경로 효과(**+0.003 / −0.037 pp**)보다 컸다. 강한 ZZ에서 matched D₁ correlated 원본을 D₀ 일반 원본과 비교하면 개발 **−0.049 pp**, 보정 **+0.244 pp**였다. 고정 raw 기준과 셀별 raw 기준의 정책 효과를 구분해야 하는 이유다.

## 재현과 다음 단계

96개 예측 파일의 해시와 정답을 확인했다. D₀ 일반의 margin과 paired 예측은 2단계 기록을 재현했다. 네 셀에서 각 정책의 고정·전체 mask를 독립적으로 다시 디코딩했고, 예측 일치와 개선·악화 집계를 확인했다. 매칭 실패는 0건이었다. 후보 생성부터 네 조건의 선택까지 worker 2개로 약 35.6분이 걸렸다. 회귀 테스트 35개와 문법 검사를 통과했다.

```powershell
conda activate fp
$env:MKL_THREADING_LAYER = 'SEQUENTIAL'
python tools/evaluate_d7_active_prior.py run
python tools/summarize_d7_active_prior.py
```

4단계에서는 기존 shot별 margin을 유지하고 raw 및 별도로 고정할 paired 대조군과의 비교를 새 맵 생성 전에 명시한다. G₁/D₁ correlated는 원래 계획의 보조 비교로 다룬다. 이 단계에서는 기존 개발·보정 자료를 사용했으므로 독립 평가 결과는 4단계에서 얻는다. [논문 완성 계획](../PREDECODER_PAPER_COMPLETION_PLAN.md)
