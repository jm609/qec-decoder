# d7 논리 클래스별 채택 모델 결과

2026-11-17 · 강한 ZZ, D₀ 일반 PyMatching · [평가 규약](../PREDECODER_D7_ADOPTION_PROTOCOL.md)

## 개발

후보 생성기 대조 실험에서 사용한 24개 맵을 개발 데이터로 사용했다. 학습 후보를 다시 디코딩해 저장한 논리 예측과 일치함을 확인했다. 맵 하나씩 제외하는 교차검증에서 학습 후보 채택 모델의 기준값은 0.025였다. 98,304 모델–shot 쌍에서 691쌍을 변경했고 371쌍을 복구하고 319쌍을 악화시켰다. 순이득은 +0.053 pp였다. 비용 모델의 두 정책은 기준값 0.50에서 원본을 유지했고 개발 순이득은 0.000 pp였다. 각 정책의 기준값은 개발 맵의 순이득이 최대인 값으로 정했다. ## 독립 평가

모델과 기준값을 동결한 뒤 새 잡음 맵 24개에서 512 shot씩 평가했다. 실제 표본은 12,288 shot이고 원본 정확도는 86.613%였다. 학습 후보 채택 모델과 후보 제약 비용 모델은 각 shot을 고정한 checkpoint 8개에서 평가했다. 원본 대비 맵별 차이를 동일 가중했다.

| 정책 | 논리 예측 변경 | 복구 | 악화 | 원본 대비 순이득 (pp) |
| --- | ---: | ---: | ---: | ---: |
| 학습 후보 채택 | 757 | 351 | 401 | **−0.051** |
| 비용 모델, 후보 제약 | 0 | 0 | 0 | 0.000 |
| 비용 모델, 제약 없음 | 0 | 0 | 0 | 0.000 |

학습 후보 채택의 정확도는 86.562%였다. 원본 대비 24개 맵 중 5개에서 개선, 3개에서 동률, 16개에서 악화였다. 나머지 5개 변경은 원본과 새 예측이 모두 오답이었다. 두 비용 정책은 평가에서 모두 원본과 같은 예측을 반환했다. 이에 따라 두 주 비교인 원본 대비와 후보 제약 비용 모델 대비의 97.5% 맵 단위 신뢰구간은 **[−0.199, +0.097] pp**로 같았다. 독립 평가에서 순이득은 확인되지 않았다. ## 전환과 계산 비용

채택 모델은 세 XOR 대안을 고려했고, 실제 757개 변경은 모두 Z 전환이었다. 원본 오답 1,645개 중 정답으로 바꾸는 데 필요한 전환은 Z 1,637개, X 7개, XZ 1개였다. 학습 후보는 Z 전환이 필요한 13,096 모델–shot 쌍 중 11,453쌍에서 정답 후보를 제공했다. 이 조건의 실제 순이득은 학습 후보가 제시한 Z 전환 중 원본 오답을 고치는 경우와 원본 정답을 해치는 경우를 얼마나 잘 가려내는지에 달려 있었다.

512-shot CPU 배치에서 원본 특징과 클래스별 제약 비용 계산은 맵당 중앙값 411 ms였다. 학습 후보 생성, 후보 후단 디코딩 및 후보 특징 계산은 맵–checkpoint당 중앙값 1,434 ms였다. 두 CPU worker로 맵을 병렬 평가했으며 데이터 및 checkpoint 로딩 시간은 이 수치에서 제외했다.

## 재현 및 검증

Anaconda `fp`에서 후보 순서와 논리 출력 재현, 원본 및 대안 선택 동률·대안 부재 점검, 경계 parity 매칭과 잡음 평가 단위 테스트를 완료했다. 독립 표본 파일 24개와 예측 파일 24개의 해시를 검증했다. 저장 확률로 정책의 변경 여부를 다시 계산하고, 저장 정답에서 복구·악화 건수와 맵 단위 구간을 재집계했다.

```powershell
conda activate fp
$env:MKL_THREADING_LAYER = 'SEQUENTIAL'
$env:OPENBLAS_NUM_THREADS = '2'
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
python -m py_compile tools/evaluate_d7_adoption.py
python tools/evaluate_d7_adoption.py develop
python tools/evaluate_d7_adoption.py freeze
python tools/evaluate_d7_adoption.py run
```
