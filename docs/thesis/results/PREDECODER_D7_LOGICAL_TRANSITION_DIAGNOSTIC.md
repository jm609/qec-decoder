# d7 논리 전이별 후보 선택 오류 분석

2026-11-16 · Anaconda `fp` 환경에서 실행

강한 ZZ 조건(G₁)에서 기존 1위 후보는 원본 PyMatching 대비 정확도를 8.501 pp 낮췄다.
원본 정답을 오답으로 바꾼 25,126건 모두에서 원본과 같은 논리 예측을 내는 다른 수정 후보가
있었다. 1위가 수정한 shot을 그대로 두고 정답을 기준으로 수정 후보를 고르면 원본 대비
+6.107 pp까지 회복할 수 있었다. [집계 JSON](../../../artifacts/eval/d7_logical_transition_diagnostic/20261116/summary.json)

## 분석 조건

이전 잡음 변화 평가에서 저장한 후보·예측 파일 64개를 재집계했다. 주 비교는 기준 DEM(D₀)의
일반 MWPM으로 고정했다. G₀(`zz_factor=0.05`)와 G₁(`0.25`) 각각 맵 8개, 맵당 5,376 shot을
사용했다. 네 checkpoint(2, 11, 54, 57)가 같은 shot을 공유한다. 아래 건수는 강도별로
43,008 shot에서 얻은 모델–shot 172,032쌍을 기준으로 한다. 나머지 DEM·디코더 조합과 모델별
집계는 JSON에 기록했다. [잡음 변화 평가](PREDECODER_D7_NOISE_SHIFT_RESULTS.md)

두 observable을 기존 순서에 따라 `I`, `X`, `Z`, `Y`로 표시했다. 전체 후보 oracle은
원본 유지와 모든 저장 수정 후보 중 정답을 고른다. 수정 shot을 고정한 oracle은 기존
경로가 수정한 shot에서 비영 수정 후보만 고르고, 기존 경로가 원본을 유지한 shot에서는
원본을 유지한다. 두 oracle은 정답을 사용한 사후 상한이다.

## G₁에서 기존 1위가 틀린 이유

| 기존 1위의 오류 | 모델–shot 쌍 |
| --- | ---: |
| 원본은 정답이었고, 다른 수정 후보가 원본 정답을 보존 | 25,126 |
| 원본은 정답이었고, 원본 유지로만 회복 가능 | 0 |
| 원본도 오답이었고, 1위가 수정했으나 다른 수정 후보가 정답 | 5 |
| 원본도 오답이었고, 1위가 원본을 유지했으나 수정 후보에 정답이 있음 | 9,352 |
| 정답을 내는 후보가 없음 | 3,554 |

1위 후보는 원본 오답 10,501건을 바로잡았다. 원본 정답을 해친 25,126건 중 18,971건
(75.5%)은 `Z → I`(11,421건) 또는 `I → Z`(7,550건)였다. `Y → X`는 3,498건,
`X → Y`는 2,657건이었다. 원본 오답 23,412건 중 정답 후보가 없었던 비율은 15.2%였다.

| 잡음과 경로 | 실제 순이득 | 수정 shot 고정 oracle | 전체 후보 oracle |
| --- | ---: | ---: | ---: |
| G₀ 1위 | −8.033 pp | +5.747 pp | +10.699 pp |
| G₁ 1위 | −8.501 pp | +6.107 pp | +11.543 pp |
| G₁ margin 적용 후 | −0.091 pp | +0.551 pp | +11.543 pp |
| G₁ 최종 family gate 적용 후 | 0.000 pp | 0.000 pp | +11.543 pp |

표의 순이득과 상한은 모두 같은 shot의 원본 PyMatching 대비다. G₁에서 1위와 전체
oracle의 차이 20.045 pp 중 14.608 pp(72.9%)는 수정할 shot을 그대로 두고 수정 후보를
다시 고르면 회복할 수 있었다. 나머지 5.436 pp는 1위가 유지한 원본 오답에 수정을
적용해야 회복할 수 있었다. Margin 적용 후에는 정답 후보가 있는 원본 오답 18,910건이
원본 유지로 남았다. 최종 family gate는 네 모델 모두에서 원본을 유지했다.

## 후속 실험

논리 클래스별로 기존 utility의 최댓값을 사용해도 G₁의 최고 점수 클래스에 동점이 없어
1위 선택은 그대로다. 앞선 matching 비용 실험에서도 수정할 shot을 고정했을 때 논리
예측이 바뀌지 않았다. 다음에는 후보 집합을 고정하고 논리 예측을 보존하는 수정과
바꾸는 수정의 점수를 비교하는 선택 규칙을 개발 맵에서 평가한다. 1위가 수정한 shot을
고정한 비교와 원본 유지까지 허용한 비교를 각각 측정하며, 규칙을 고정한 뒤 새 맵에서
확인한다. [Matching 비용 재순위 실험](PREDECODER_D7_MATCHING_COST_RERANK_RESULTS.md)

진단이다.
