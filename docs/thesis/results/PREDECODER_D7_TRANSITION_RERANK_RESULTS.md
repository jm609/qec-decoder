# d7 논리 전이 점수 보정 실험

2026-11-16 · Anaconda `fp` 환경에서 실행

## 비교 조건

앞선 오류 분석에서 d7의 기존 1위가 원본 정답을 바꾼 25,126쌍 모두에 원본과 같은
논리 예측을 내는 다른 수정 후보가 있었다. 이번 실험에서는 같은 후보 사이에서 논리
전이 점수를 보정했을 때 원본 정답을 해치는 수정이 줄고, 기존에 원본 오답을 고친
수정이 얼마나 유지되는지 측정했다. [사후 진단](PREDECODER_D7_LOGICAL_TRANSITION_DIAGNOSTIC.md)

재학습 checkpoint 2, 11, 54, 57의 후보 생성과 기본 점수를 고정했다. 시험 잡음은 강한
ZZ 조건(G₁, `zz_factor=0.25`)이며, 매칭은 기준 DEM(D₀, `zz_factor=0.05`)의 일반 MWPM으로
고정했다. 각 후보의 논리 전이는 원본과 후보의 두 observable 예측을 XOR해 구했다.

```text
보정 점수 = α × 기존 utility + b[원본 논리 클래스, 후보의 논리 전이]
```

`α`는 양수로 제한했고, 원본과 같은 논리 예측을 내는 클래스의 `b`는 0으로 고정했다.
개발 맵 783000, 783001의 G₁ 저장 예측에서, shot 안의 전이별 최대 utility로 조건부
softmax를 구성했다. 정답 후보가 있는 15,983 모델–shot 쌍으로 L2 규제(`0.01`)를 적용해
cross-entropy를 최소화했다. 401쌍에는 정답 후보가 없었다. 보정 후 `α=0.5574`였고,
Z 전이의 추가 점수는 원본 클래스 `I`, `X`, `Z`, `Y` 순서로 −1.0770, −0.6682,
−0.7274, −0.2628이었다. [고정 계수](../../../artifacts/eval/d7_transition_rerank/20261116/calibration.json)

계수를 동결한 뒤 새 맵 785100–785107의 맵당 1,024 shot을 평가했다. 네 checkpoint가
같은 8,192 shot을 공유하므로 건수의 분모는 32,768 모델–shot 쌍이다. 주 비교에서는
기존 1위가 수정한 shot을 고정하고, 해당 shot에서 비영 수정 후보를 다시 골랐다.
보조 비교에서는 원본 유지를 포함한 모든 후보를 다시 골랐다. 95% 구간은 모델별
차이를 맵 안에서 평균한 뒤 맵 단위 paired bootstrap 20,000회로 계산했다.
[실험 규약](../../../artifacts/eval/d7_transition_rerank/20261116/protocol.json)

## 결과

| 경로 | 수정 적용 | 원본 오답을 고침 | 원본 정답을 해침 | 원본 대비 순이득 |
| --- | ---: | ---: | ---: | ---: |
| 기존 1위 | 6,402 | 1,822 | 4,573 | −8.395 pp |
| 수정 shot 고정 후 점수 보정 | 6,402 | 1,822 | 4,573 | −8.395 pp |
| 원본 유지 허용 후 점수 보정 | 993 | 341 | 651 | −0.946 pp |

수정할 shot을 고정하면 6,402건 모두 기존과 같은 mask를 골랐다. 기존 1위 대비 차이는
0.000 pp였고, 8개 맵 각각에서도 0이었다. 원본 유지를 허용하면 5,409건에서 기존 수정을
취소했다. 원본 정답을 해친 3,922건(85.8%)을 피했으며, 기존에 원본 오답을 고친 1,822건
중 341건(18.7%)을 유지했다. 보정으로 새로 고친 원본 오답과 새로 해친 원본 정답은 각각
0건이었다. 정확도 차이는 기존 1위 대비 +7.449 pp였고(95% 구간 +6.339~+8.578 pp), 원본
PyMatching 대비 −0.946 pp였다(−1.135~−0.757 pp).
[집계 JSON](../../../artifacts/eval/d7_transition_rerank/20261116/summary.json)

기존 1위가 원본 정답을 해친 4,573건은 모두 Z 전이였다. 4,573건 모두에 원본 예측을
보존하는 비영 수정 후보가 있었다. 각 shot에서 기존 1위와 가장 높은 점수의 보존 수정
사이의 차이를 `α × (기존 1위 utility − 보존 수정의 최대 utility)`로 계산했다. 이 차이는
중앙값 4.152였고, Z 전이 감점은 0.263~1.077이었다. 감점 후에도 기존 1위가 모든 해당
shot에서 보존 수정에 최소 0.700점 앞섰다. 이 점수 보정은 수정 후보끼리의 순위를 바꾸기엔
작았고, 일부 shot에서는 원본 유지가 기존 1위를 이겼다.

같은 새 맵에서 기존 selector margin 경로를 사후 집계하면 원본 오답 173건을 고치고
원본 정답 230건을 해쳐 −0.174 pp였다. 이번 보정의 효과는 G₁에서 시험한 규칙과 네
checkpoint에 해당한다. 두 observable 예측을 만드는 매칭 호출 비용은 이번 비교에서
성능 지표로 측정하지 않았다.
