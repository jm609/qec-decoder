# d7 Z 전이와 주변 detector 패턴

2026-11-16 · Anaconda `fp` 환경에서 실행

개발 맵 두 개에서 기존 margin과 같은 수의 원본 오답을 고쳤을 때, 수정 주변 detector
패턴을 사용한 점수는 원본 정답을 해치는 수를 109건에서 84건으로 줄였다. 학습 맵에서
고정한 적용 기준을 반대편 맵에 그대로 적용하면 개선과 악화가 각각 86건이었다.
[집계 JSON](../../../artifacts/eval/d7_z_transition_probe/20261116/summary.json)

## 분석 조건

강한 ZZ 조건(G₁, `zz_factor=0.25`)에서 기준 DEM(D₀)과 일반 MWPM을 사용했다. 개발 맵
783000, 783001의 맵당 2,048 shot을 네 checkpoint(2, 11, 54, 57)가 공유한다. 저장된
후보와 예측에서 기존 1위가 비영 수정으로 Z 전이를 일으킨 모델–shot 쌍 2,998개를
골랐다. 여기서 Z 전이는 원본과 후보 간 두 observable 예측의 XOR가 `Z`인 경우다.
기존 1위는 이 집합에서 원본 오답 883건을 고쳤고 원본 정답 2,113건을 해쳤다.
원본과 후보가 모두 틀린 2건은 적용 건수에 포함했고 이진 분류 학습과 AUC에서 제외했다.
[이전 전이 점수 보정 실험](PREDECODER_D7_TRANSITION_RERANK_RESULTS.md)

개발 맵 하나에서 L2 로지스틱 회귀(규제 계수 0.01)를 맞추고, 다른 맵에 적용하는
방향을 바꿔 두 번 평가했다. 대조 회귀는 기존 1위와 no-edit의 utility 차이, 수정 무게,
원본 논리 클래스, checkpoint, 주변 detector 유효 위치와 수정 mask를 사용했다.
detector 패턴을 넣은 회귀에는 같은 입력에 수정 위치 주변의 3×3×3 detector event와
수정 대상으로 지정된 detector 중 실제 활성화된 수를 추가했다. 패치는 편집 좌표를
시간·행·열 순으로 정렬한 첫 위치에 맞췄다. 정답은 학습 대상과 집계에 사용했다.

## 개발 맵 결과

| 검증 맵 | 기존 margin 개선 / 악화 | 대조 회귀 개선 / 악화 | detector 패턴 개선 / 악화 |
| --- | ---: | ---: | ---: |
| 783000 | 42 / 63 | 42 / 60 | 42 / 48 |
| 783001 | 43 / 46 | 43 / 41 | 43 / 36 |
| 합계 | 85 / 109 | 85 / 101 | 85 / 84 |

표에서는 검증 맵의 정답을 사용해 기존 margin과 개선 건수가 같아지는 지점에서 순위를
비교했다. 이 기준으로 detector 패턴은 기존 margin 대비 악화를 25건(22.9%), 대조 회귀
대비 17건 줄였다. 개선과 악화를 구분하는 AUC는 783000에서 0.608에서 0.651로,
783001에서 0.607에서 0.653으로 올랐다.

학습 맵에서 기존 margin의 개선 건수에 맞춰 적용 기준을 고정하면, 검증 맵에서 각각
40건 개선·47건 악화와 46건 개선·39건 악화였다. 두 맵 합계는 86건 개선·86건 악화다.
원본 유지와 기존 1위 Z 전이 사이의 선택만 평가했으므로, 이 결과는 기존 후보 사이의
재순위 성능이나 새 맵의 전체 디코더 정확도로 해석할 수 없다. 다음 selector 실험은
원본 예측을 보존하는 수정 후보와 Z 전이 후보를 같은 shot에서 직접 비교하는 데 초점을
둔다.

예측 파일 8개의 해시를 검증했다. 회귀 테스트 30개를 통과했다.
